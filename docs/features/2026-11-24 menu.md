# Menu: choose and order the parts

Each person chooses, per device, which parts of Kanso the rail shows and in
which order (`/me/menu`, from the user menu and from "Mehr"). Start always
stays. On phones the first four visible parts sit in the bar and the rest go
under "Mehr". On wide screens the column scrolls. Settings live in the
browser, not in a cookie and not on the server.
