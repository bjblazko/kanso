# AI connection and recipe import

Admins register one language model under "KI-Anbindung" (any OpenAI-compatible
service: Ollama, OpenRouter, OpenAI …; token optional) and test it. In the
kitchen, "Von Webseite" turns a recipe page into a recipe draft: from the
page's own recipe data where it has some, otherwise with the AI. The person
checks the draft and only then creates the recipe.
