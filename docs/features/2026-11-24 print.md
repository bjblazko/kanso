# Print

Every page prints as its content alone: no menu, toolbars, buttons, forms or
footer, black on white, with sensible page breaks. External links get their
address after them, and images fit the page. Wiki pages, recipes, notes and
tasks have a quiet "Drucken" button that opens the browser's print dialog,
which can also save a PDF. Kanso has no PDF tool of its own.
