# Tasks

Things that come up between door and hinge and fit no to-do list. Captured on
the phone in seconds (title, board, urgent, important, due), also offline;
sorted at the desk. One private board per person and a family board from which
anyone takes a task. Each board has two tabs, Kanban (Offen · In Arbeit ·
Wartet · Erledigt) and Eisenhower matrix, showing the same tasks. A task has a
title and optional Markdown text; a note can become a task. No recurring tasks.

Cards are dragged between columns and quadrants on the desktop; on the phone
the task's own page changes column and priority. Done tasks stay in Erledigt
for 14 days, older ones on request. Admins create group boards
(`/admin/boards`); every member of the group sees and edits them, admins only
as members. Every board says who can see it (ADR-007).
